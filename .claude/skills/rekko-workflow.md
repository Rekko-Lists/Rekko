# Skill: Rekko Workflow

## Flujo recomendado

1. Leer el requisito completo y ubicar archivos afectados.
2. Aplicar cambios minimos y enfocados.
3. Ejecutar validaciones (`npm run build` y, cuando proceda, `npm run dev`).
4. Revisar errores del editor y warnings relevantes.
5. Documentar cambios en el PR/commit de forma breve.

## Convenciones de commit inicial sugeridas

- `chore: bootstrap rekko frontend`
- `chore: add project docs and agent skills`
- `fix: remove deprecated tsconfig options`

## Definition of Done

- Build exitoso.
- Sin errores TypeScript bloqueantes.
- README y `.gitignore` presentes.
- Estructura `.claude` creada y coherente.
